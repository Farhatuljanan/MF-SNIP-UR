# Maximum Flow Stochastic Network Interdiction with Uncertain Restructuring
This repository contains the data and code associated with the paper "Maximum Flow Stochastic Network Interdiction with Uncertain Restructuring: Applications to Local-Level Drug Trafficking Enforcement" by Farhatul Janan, Thomas C. Sharkey, and Emily Tucker, and this article is published at IISE Transactions. Find the article at https://www.tandfonline.com/doi/full/10.1080/24725854.2025.2597931?scroll=top&needAccess=true.
For any inquiries regarding the data, code, or related matters, please contact fjanan@clemson.edu.
