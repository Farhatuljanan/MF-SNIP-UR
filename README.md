# Maximum Flow Stochastic Network Interdiction with Uncertain Restructuring
This repository contains the data and code associated with the paper "Maximum Flow Stochastic Network Interdiction with Uncertain Restructuring" by Farhatul Janan, Thomas C. Sharkey, and Emily Tucker.
The authors are happy to give access to the codes upon reasonable request. For any inquiries regarding the data, code, or related matters, please contact fjanan@clemson.edu.
