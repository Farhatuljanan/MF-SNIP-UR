# Maximum Flow Stochastic Network Interdiction with Uncertain Restructuring
This repository contains the data and code associated with the paper "Maximum Flow Stochastic Network Interdiction with Uncertain Restructuring: Applications to Local-Level Drug Trafficking Enforcement" by Farhatul Janan, Thomas C. Sharkey, and Emily Tucker.
For any inquiries regarding the data, code, or related matters, please contact fjanan@clemson.edu.
